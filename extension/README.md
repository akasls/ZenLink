# ZenLink Chrome 快捷扩展助手

专为 **ZenLink 个人网址导航与知识工作台** 打造的浏览器快捷扩展（基于 Chrome Manifest V3 规范），支持快速连接任意自建 ZenLink 服务端、一键收藏当前网页、即时搜索与浏览书签。

---

## 🌟 核心特性

- 🔗 **自建服务自由连接**：支持输入任意自建 ZenLink 实例地址（公网域名、内网 IP、Localhost 均可）。
- 🔐 **安全认证与 2FA 支持**：支持管理员账号密码登录与 TOTP 两步验证码，Token 安全加密保存在浏览器本地。
- ⚡ **一键极速收藏**：自动读取当前活动标签页的 URL、网页标题与高清 Favicon 图标。
- 🤖 **AI / 自动元数据提取**：支持调用服务端的网站爬虫与大模型元数据提炼引擎，一键精炼地道中文简介与核心品牌名称。
- 🔍 **即时搜索与分类筛选**：在扩展弹窗内随心搜索书签（支持标题、描述、URL 模糊匹配），支持横向滑动胶囊分类筛选。
- 🖱️ **右键上下文菜单快速收藏**：无需点开插件弹窗，在任意网页右键即可选择「添加当前网页至 ZenLink」或「添加链接至 ZenLink」。
- 🌓 **原生暗黑/明亮主题自适应**：根据您的系统偏好无缝切换暗黑与浅色模式。

## 🚀 安装步骤（开发者模式加载）

适用于 **Google Chrome**、**Microsoft Edge**、**Brave**、**Arc**、**Vivaldi** 等所有 Chromium 内核浏览器：

1. **打开浏览器扩展管理页面**：
   - **Chrome**: 在地址栏输入 `chrome://extensions/` 并按回车。
   - **Edge**: 在地址栏输入 `edge://extensions/` 并按回车。
2. **开启「开发者模式」**：
   - 在扩展管理页面的右上角（Edge 为左侧或右上角），将 **「开发者模式 (Developer mode)」** 开关打开。
3. **加载已解压的扩展程序**：
   - 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」** 按钮。
   - 在弹出的文件夹选择框中，选择本项目下的 **`extension`** 文件夹（即包含 `manifest.json` 的目录）。
4. **固定到工具栏**：
   - 点击浏览器右上角的扩展拼图图标 🧩，找到 **ZenLink 快捷助手**，点击图钉 📌 按钮将其固定到工具栏，方便随时调用！

## 💡 使用指南

### 1. 首次登录与服务器绑定
1. 点击浏览器右上角 ZenLink 图标打开弹窗；
2. 输入您的服务端地址，例如：
   - 本地开发：`http://127.0.0.1:3000`
   - 自建云服务器/NAS：`https://nav.yourdomain.com`
3. 输入您的管理员账号与密码（若启用了两步验证，输入 6 位动态验证码）；
4. 点击 **「连接并登录」**，验证通过后将自动进入主界面并同步分类与书签。

### 2. 收藏当前正在浏览的网页
- **方法一（弹窗确认）**：
  1. 打开任意感兴趣的网页；
  2. 点击右上角 ZenLink 扩展图标；
  3. 顶部的「当前页面」横条会自动显示该网页，点击 **「一键保存」** 或右上角的 **「添加」**；
  4. 检查或修改标题、所属分类与简介（可点击「AI / 自动识别」智能润色）；
  5. 点击 **「保存至导航」** 即可。
- **方法二（右键快捷保存）**：
  - 在网页任意空白处点击鼠标右键，选择 **「添加当前网页至 ZenLink」**；
  - 扩展后台会自动将其提交到服务端，并在屏幕右上角弹出保存成功的系统通知。

### 3. 快捷键唤起
- Windows / Linux：`Alt + Z`
- macOS：`Option + Z`
*(可在浏览器的快捷键管理页面 `chrome://extensions/shortcuts` 自定义)*
